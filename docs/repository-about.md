## Longer project summary

Brawn brings routine planning and workout execution into a single interface. Users organize exercises and sets, follow a session with a timer and rest controls, and save completion summaries in MongoDB. The React frontend uses reusable controls and Context providers to share authentication, training, timing, and social UI state. Brawnify optionally converts written requests into editable routine data through an external model integration. Feed, story, reel, creator, and messaging screens demonstrate browser-local interactions rather than a deployed multi-user social network.
